# Privora 5.0.0-dev.6.61 — Update Reliability & Live Domain Reconciliation Repair

## Live defects addressed

- PCC Update Center refresh must not return HTTP 500 merely because the privileged agent status endpoint or transaction metadata is unavailable.
- Update migrations are bounded: preflight uses a 90s timeout and apply uses a 180s timeout.
- Routine successful updates preserve an already-active PCC PHP-FPM runtime instead of blindly restarting it and killing the browser session.
- Known hosted root domains cannot disappear from DNS Zone Manager. If no local authoritative zone is confirmed, the domain remains visible as `not-configured` with an explicit status reason.
- Local authoritative DNS discovery checks `rndc zonestatus` and detected local DNS listeners instead of assuming only `127.0.0.1`.
- Legacy website reconciliation can use the recorded document root against the effective `nginx -T` configuration when unusual vhost formatting prevents exact `server_name` parsing.

## Certification

The 6.61 dedicated reliability regression gate passed, including Go hostadapter/API tests, PHP syntax, updater invariants, DNS visibility, and legacy-vhost reconciliation.

The complete Privora verification suite was executed in bounded certification lanes because the monolithic wrapper exceeded the execution window.
