# Privora 5.0.0-dev.6.63 — DNS Creation Contract Repair

Live pattern: older root domains remained configured while later-created `privoralabs.com`, `demo.privategather.com`, and `downloads.privoralabs.org` remained unconfigured.

Root cause addressed:
- new root zones created after branded nameservers already existed could omit in-bailiwick A/AAAA records for the configured authoritative `ns1/ns2` hosts before `named-checkzone` validation;
- child hostnames were still being surfaced like independent authoritative zones instead of being evaluated as records in their parent zones.

6.63 changes:
- automatically adds required in-bailiwick nameserver A/AAAA records before new root-zone validation;
- never injects foreign nameserver glue into unrelated customer zones;
- classifies child hostnames under their longest hosted parent zone;
- DNS Zone Manager reports `CONFIGURED VIA PARENT` or `PARENT RECORD MISSING` for child hostnames;
- existing hosted-DNS repair reuses the corrected provisioning contract.
