# Privora 5.0.0-dev.6.64 — Agent Handoff & Root DNS Truth

Live evidence after 6.63: `demo.privategather.com` and `downloads.privoralabs.org` were correctly classified via their parent zones, but `privoralabs.com` still showed `NOT CONFIGURED`. The same update also exposed a brief `Agent unavailable` error during the deferred agent refresh.

6.64 changes:
- PCC retries Unix-socket connection establishment during the bounded post-update agent restart window.
- Post-update hosted-DNS reconciliation waits for a healthy agent `/v1/health` response instead of merely waiting for the socket pathname.
- DNS reconciliation retries transient post-restart failures and persists the last structured result/error to `/var/lib/privora-panel/dns-reconcile-last.json`.
- DNS Zone Manager displays per-domain repair status/reason directly in the UI.
- DNS-only inventory falls back to `rndc zonestatus` for hosted root domains if effective BIND configuration parsing is degraded, so a genuinely loaded legacy root zone cannot be mislabeled `NOT CONFIGURED`.
- Child hostnames remain classified via their longest hosted parent zone.
